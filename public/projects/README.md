# Project artwork

Spendy iOS banner combines the five original campaign cards from Figma file Z1P9Kg0l8UUomBl8gjfT72, page 42:2: Home (42:3), Receipt scanner (42:59), Spending insights (42:209), Analytics (42:264), Home Screen widgets (42:280). All five cards are shown in full.

Spendy website and PWA banners use real local browser captures. The PWA capture uses a synthetic demo ledger in a fresh temporary browser; no personal data is used. The website is a separate project from the app; iOS remains in development.

Breeze’s banner is exported directly from editable Figma frame 96:3 on page 96:2 (Breeze · iPhone 17 Pro artwork), in file Z1P9Kg0l8UUomBl8gjfT72. It reuses the silver iPhone framing from the Spendy artwork and places the existing fan-inside-ring.png and compact-island.png UI-preview captures into the devices. The icon is Breeze’s original app icon. Text uses SF Pro; background and text colours use local Figma variables. The exported artwork is compressed to 1600px and 800px WebP, preserving the Figma composition.

Other banners frame the pre-existing project images without changing their content. Banners are supplied at 1600 × 900 and 800 × 450, with responsive srcSet, lazy loading, and asynchronous decoding.
